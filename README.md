| 目录 | 放什么 |
|---|---|
| `LOG.md` | 每日日志（每天 5 分钟） |
| `cases/` | 每日案例笔记，一天一个文件 |
| `job-search/` | 投递记录（`applications.csv` 可导入 Google Sheets） |
| `interviews/` | 企业访谈、校友交流、模拟面试笔记 |
